### go-zero

下载和配置很简单，去网上搜索即可。->[官网教程](https://go-zero.dev/zh-cn/getting-started/)

```bash
goctl api new xxx #快速生成api服务
goctl rpc new xxx #快速生成rpc服务
#好多教程包括ai都没将明白，因为我有点洁癖，希望文件放在他该放的位置。而直接快速生成rpc服务没法指定输出的文件夹目录，然后终于发现go-zero是很难符合我想的架构，他的client包只能与service放一起，我想的是./api下放其他服务导入的包，而./proto放协议。不过先就这样了。
goctl rpc templet -o ./proto/user/v1 #这个用于输出proto协议
goctl rpc protoc ./proto/user/v1/user.proto --go_out=./service/userservice  --go-grpc_out=./service/userservice  --zrpc_out=./service/userservice  
goctl model mysql ddl -src="./user.sql" -dir="./internal/model" -c   
goctl model mysql datasource -url="user:password@tcp(127.0.0.1:3306)/your_database" -table="user" -dir="./internal/model" -c
```
