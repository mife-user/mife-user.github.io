# 前言
写一些零碎的小知识，方便在忘记时查看

## 如何查看文件占用
当你想删除某个文件时，常常会弹出xxx被占用，输入
```
win+r 
resmon
```
选择CPU，在关联句柄中输入要删除的文件路径（无""），查找到后右键结束进程即可，然后可以删除文件

## 如何快速处理一般网络问题

1. 关闭VPN
2. 开启vpn
3. 以管理员运行powershell
```powershell
net stop winnat
net start winnat
```
4. 关闭校园网
5. 重启电脑
