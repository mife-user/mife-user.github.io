## 认识 STM32 开发板

![stm32](/images/stm32.webp)

1. STM32F103C8T6 芯片：相当于开发板的大脑，负责执行程序。
2. GPIO 引脚：用于控制 LED、按键、蜂鸣器等外设。
3. BOOT0 跳线：决定芯片的启动方式，正常运行用户程序时通常设为 0。
4. SWD 接口：用于连接 ST-Link，下载程序和调试。
5. 电源接口：可以通过 USB 或正确接线的 ST-Link 为开发板供电。

先为软件选择烦劳，发现2无法适配STM32F103C8T6，于是下载了1.

在界面选择启动对应芯片，然后配置：

按照下面步骤操作：
1. 点击左侧的 System Core（系统核心），展开菜单。
2. 在展开的菜单中找到 SYS，点击它。
3. 在右侧出现的配置页面中，找到 Debug。
4. 点击 Debug 右侧的下拉框。
5. 选择 Serial Wire。
目标配置
SYS → Debug
Serial Wire


为什么要选择 Serial Wire？
STM32F103C8T6 使用以下两个主要引脚进行 SWD 调试：

| STM32 引脚 | ST-Link V2 接口 | 作用 |
| :--------- | :-------------- | :------------------------ |
| PA13       | SWDIO           | 传输调试数据 |
| PA14       | SWCLK           | 提供调试时钟 |
| GND        | GND             | 共地 |

选择 Serial Wire 后，PA13 和 PA14 会被保留用于 SWD 调试，避免被普通 GPIO 配置占用。

注意： SWO（PB3）不是 SWDIO，不能用它代替 PA13。

![示例](/images/stm示例版.webp)

SWD 调试接口：PA13、PA14，用于 ST-Link 下载程序和调试。

LED 输出接口：PC13，用于控制开发板上的 LED。
