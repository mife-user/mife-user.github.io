## 1. 计算机系统概述

### 1.1 操作系统的概念、功能和目标

#### 1.1.1+1.1.2 操作系统的概念、功能和目标

结构：
```mermaid
  flowchart TB
  用户 --> Y
  用户 --> C
  Y[应用程序] --> C
  C[操作系统] --> 裸机
```

*操作系统*：控制和管理计算机系统的硬件和软件资源，组织调度计算机的工作和资源分配以提供给用户和其他软件方便的接口和环境，是系统最基础的系统软件

功能：
- 处理器管理
- 存储器管理
- 文件管理
- 设备管理
- ......

一些服务：
- GUI（比如windows的图形拖拽）
- 命令接口：
  - 联机命令接口（交互式命令接口）
  - 脱机命令接口（批处理命令接口）
- 程序接口，通过系统调用所有程序接口（比如C++中std::cout<<"hello world"实际调用的系统的接口）
- ......

#### 1.1.3 操作系统的特征

特征：
- 并发
  - 并发：同一时刻间隔发送，微观上交替发生
  - 并行：同时发生
- 共享：
  - 互斥共享方式
  - 同时共享方式
- 虚拟：将物理实体变化为逻辑产物，虚拟技术中如虚拟处理器技术，虚拟存储器技术等，分别采用了空分复用（拆分空间）和时分复用技术（拆分时间交替运行）
- 异步：多个程序运行允许并发执行而不是串行（即走走停停，不可预知速度）


### 1.2 操作系统的发展与分类

1. 手工操作阶段：通过纸带写程序，用户独占全机
2. 批处理阶段：
     - 单道批处理系统：通过外围机存放到磁带机，引入脱机输入/输出技术，由监督程序复杂作业的输入，输出。
     - 多道批处理系统：多道程序并发执行，无人机交互
3. 分时操作系统：划分时间处理不同用户，对各个用户完全公平
4. 实时操作系统：可以处理紧急任务，及时且可靠
5. 网络操作系统
6. 分布式操作系统
7. ......

### 1.3 操作系统的运行机制

#### 1.3.1 操作系统的运行机制

- 内核程序：操作系统
- 应用程序：一般开发的程序，如QQ等

CPU的两种状态：CPU通过一个寄存器程序状态字寄存器（PSW）标记不同状态（1：内核态，0：用户态（不同CPU可能不同））
- 内核态：通过特权指令蟹盖PSW改为用户态允许用户程序
- 用户态：当触发中断时，操作系统强制切换为内核态

#### 1.3.2 中断和异常

中断是让操作系统内核夺回CPU使用权的唯一途径

类型：
- 内中断：陷入指令或特权指令
  - 故障（fault）
  - 终止（abort）
  - 陷入（trap）
- 外中断：来自外部的中断信号，如时钟中断...
  - 时钟中断
  - I/O中断请求

基本原理：

CPU根据不同的中断信号用不同的中断程序处理，根据类型查询“中断向量表”
#### 1.3.3 系统调用

按功能分类：
- 设备管理
- 文件管理
- 进程管理
- 进程通信
- 内存管理

```mermaid
flowchart  LR
A[调用库函数] --> B[处理相关指令]
B --> C[传参指令，将系统调用需要的参数存放道某些通用寄存器中]
C --> D[陷入指令（trap指令/访管指令）]
D --> E[处理后续相关指令]

```
注：凡是与共享资源有关的操作，会直接影响其他进程的操作，就一定需要操作系统介入
